Sidebar Navigation Project


‎
‎A  simple, responsive sidebar navigation built with HTML, CSS, and JavaScript. 


It features smooth open/close transitions and an animated sign-out confirmation popup. 


The design is modern and clean, perfect for portfolios, dashboards, or web apps.


‎
‎Features


‎1. Responsive sidebar that works well on desktop, tablet, and mobile.


‎2. Smooth animation opens and closes the sidebar.


‎3. Animated sign-out confirmation pops up when clicking the profile.


‎4. Confirmation window has "Yes" and "No" buttons with feedback animations.


‎5. Clean, minimal UI with soft shadows and hover effects.


‎6.  Uses Google Fonts: DM Sans, Architects Daughter, and EB Garamond.


‎7.Stylish green color theme for a professional look.


‎8.Simple code that’s easy to customize and reuse.
